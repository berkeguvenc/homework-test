# Vitest ile Test Yazma Ödevi

Bu proje, "Hafta 5 - Gün 2" kapsamında verilen Vitest ve React Testing Library pratiklerini içeren bir ödev projesidir.

## Proje İçeriği

Ödev kapsamında aşağıdaki görevler tamamlanmıştır:

1. **Sepet Modülü**: AAA pattern kullanılarak birim testleri yazılmıştır.
2. **Selam Mesajı V2**: Fake timer'lar (`vi.useFakeTimers`) kullanılarak zamana duyarlı testler yapılmıştır.
3. **Hava Durumu API**: `global.fetch` mock'lanarak API istekleri test edilmiştir.
4. **TodoList Component**: React Testing Library ve `@testing-library/user-event` kullanılarak component testleri yazılmıştır.

## Kurulum ve Çalıştırma

Bağımlılıkları yüklemek için:
```bash
npm install
```

Testleri çalıştırmak için:
```bash
npm test
```

Test kapsama oranını (coverage) görmek için:
```bash
npm test -- --coverage
```
